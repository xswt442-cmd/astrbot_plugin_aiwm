# 爱完美

AstrBot 插件。通过完美世界竞技平台接口读取 CS2 战绩，交给大模型做锐评和玩家画像。

## 它能读到什么

一次请求就能拿到：

- 段位与综合分、生涯累计胜场、近期统计场次与胜率
- KD、Rating、ADR
- KAST、RWS、爆头率、首杀率、AWP 击杀占比、闪光成功率
- 常用地图（含场次）、常用武器（含击杀与爆头数）
- 三杀四杀五杀次数、当前连胜、最近十场评分序列、游戏时长

ADR（每回合平均伤害）、KAST（每回合有贡献的比例）、RWS（队伍胜率中由该选手
贡献的比例）是 FPS 特有的深度指标，MOB 类游戏没有对应物。术语见
[docs/GLOSSARY.md](docs/GLOSSARY.md)。

## 安装

在 AstrBot 的插件市场里搜「爱完美」，或手动把仓库放到 `data/plugins/astrbot_plugin_aiwm`。

只依赖 `aiohttp`，不需要额外服务。

## 配置

没有配置项。

完美平台的战绩接口对查询目标不校验身份，所以插件**不需要登录平台、没有扫码、没有 token**。绑定只是记一个 steamid64。

## 用法

```
/爱完美 绑定 <你的 steamid64 或任何含它的内容>
/爱完美 战绩
/爱完美 锐评
/爱完美 PK <名字>
/爱完美 昵称 <名字>
/爱完美 解绑
/爱完美 状态
/爱完美 帮助
```

直接问模型「我的 CS2 战绩怎么样」也会走同一套数据。

### 绑定时不用自己挑数字

steamid64 是一串 17 位数字、以 7 开头。`/爱完美 绑定` 接受任意内容，会自己从
里面提取，下面这些都能直接粘：

- Steam 个人资料页的网址（`.../profiles/76561198159976336`）
- 启动器参数（`steam.exe -login 76561198159976336`）
- 那串数字本身

找不到时报错会告诉你怎么找。内容里有好几个 id 时会问你发哪个，不瞎猜。

### 关于 PK

`/爱完美 PK` 要的是**绑定时记下的 PK 名字**，不是 Steam 昵称。首次绑定后用 `/爱完美 昵称` 设一个：

```
/爱完美 昵称 老王
/爱完美 PK 老王
```

这是因为 QQ 官方平台上 @ 别人拿不到对方的用户标识（适配器只把「@机器人」转成消息组件，被 @ 的人在事件里完全没有痕迹），所以只能靠名字点人。

## 数据从哪来

`https://api.wmpvp.com/api/csgo/home/official/detailStats`，完美世界竞技平台的内部接口。没有公开文档，字段以真实响应为准。

国服有两家对战平台，本插件只支持完美平台，5EPlay（`5eplay.com`）不在范围内。

玩家在完美平台关闭战绩展示时，接口返回的是空壳数据，插件会照实说明而不会编数字。

## 开发

```sh
uv sync
uv run pytest
uv run ruff check .
uv run ruff format --check .
```

手工验证整条链路：

```sh
uv run python test/verify_wmpvp.py <steamid64>            # 打印数据与原始响应
uv run python test/verify_wmpvp.py <steamid64> --检查     # 核对字段名与量纲
```

测试用构造的数据。完美平台的接口没有公开文档，字段与量纲随时可能变——改协议
相关代码前先跑 `--检查`，它会报出是哪个字段变了。持续集成里每天也跑一次。
