# 更新日志

本文件记录这个插件对外可见的变化。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.8] - 2026-10-14

### 修正

- **换一个可用的版本号。** `v0.1.7` 已在插件市场登记过，平台不允许同一个版本号
  二次使用——即使把插件删除或撤回也不行，提交时会报「该版本号已经使用过」。
  除版本号外与 v0.1.7 内容相同。

## [0.1.7] - 2026-10-14

### 修正

- **组名补上带斜杠的别名。** QQ 官方的 At 唤醒分支不剥 `message_str` 里的 `/`，
  `@机器人 /爱完美 战绩` 的组名匹配不上，整条指令静默失败。
- 插件描述里的「完美竞技平台」改成 CS2 官方匹配：`metadata.yaml` 与
  `pyproject.toml` 两处都改了。数据源是官匹，按描述去核对会对不上。
- `/爱完美 昵称` 不带参数时的回显把同一个值报了两遍（「当前 PK 名字：老王，
  绑定时自动取的是「老王」」）。

### 变更

- **帮助与各种回复都收短。** 帮助改成一行一条，绑定、状态、昵称、PK 的提示
  去掉重复解释；模型出错一律说「调用模型失败」，未绑定一律先说怎么绑定。
- 提示词里 PK 的「互损」改成主要攻击输的一方：双方各点一项缺点等于没有倾向，
  反而像端水。
- PK 分数改成「分差要跟两人的实际差距相符」，不再笼统要求「敢于给大的分差」；
  并钉住胜者那一行必须与分数一致。
- 开一局在模型空返回时也说明「模型没有返回内容」，不再只给一行设定。

### 工程

- 补 `release.yml`：打标签与建 Release 在同一个工作流里做，发版前核对四处
  版本号一致、main 的门禁已绿、发布包内容符合预期。
- `.gitattributes` 补行尾与二进制规则，并去掉 `docs/` 的 `export-ignore`——
  README 指向那里的术语表，排除后链接指向空路径。

## [0.1.6] - 2026-10-12

- 改掉插件描述里的「完美竞技平台」：数据来自 CS2 官方匹配，不是完美平台的
  对局记录。市场详情页显示的就是这句。

## [0.1.5] - 2026-10-12

- 修 v0.1.4 的加载失败：兜底过滤器要用 `@custom_filter` 装饰器挂，
  `self.爱完美.add_custom_filter(...)` 会报 AttributeError。

## [0.1.4] - 2026-10-12

- `/爱完美 PK` 不用等对方绑定了：直接发 steamid64 或含它的网址就能比。
  昵称那条仍在，但不是唯一路径。
- 拦下 `/爱完美 <没匹配上子命令的内容>`：以前这类消息被 AstrBot 跳过指令、
  原样进模型，模型收到一句普通提问就自己编（实测回过「考验我视力？」
  「我又没权限爬Steam」）。现在自己回一句该发什么。
- 说清数据来源：这个接口返回的是 **CS2 官方匹配（官匹）** 的数据，不是完美
  竞技平台的对局记录。以前输出里写着「完美平台战绩」，用户一核对就对不上。
- 提示词加一条硬要求：只说数据支撑得住的话。模型以前会把数据当结论编
  （「最近18连胜只是一场幻觉」「你永远不是该开第一枪的那个人」）。

## [0.1.3] - 2026-10-12

- `/爱完美 开一局`（别名 `/爱完美 开局`、`/爱完美 来一局`）：随机生成一局，
  让模型推演过程与结果。数字由代码生成，不让模型自己编；绑定过的话推演会
  贴着玩家的真实水平。输出第一行写明这是推演，不是真实战绩。

## [0.1.2] - 2026-10-12

- 换上新图标。源图在 `icon/aiwm-icon.png`，由 `test/做图标.py` 生成根目录的
  `logo.png`：缩到画布的 92% 让皇冠尖角在圆形裁切下不被切掉，并抠掉源图的
  方形深蓝底，避免裁成圆形后露出一圈方角。

## [0.1.1] - 2026-10-12

- 修 `Main.__init__` 的 `config` 参数：改成可省。AstrBot 在仓库没有配置文件时
  只传 context，声明成必需参数会让插件加载失败。

## [0.1.0] - 2026-10-12

首个版本。

- `/爱完美 绑定 <steamid64>`：绑定 SteamID64。绑定前先探一次接口，打错数字会当场报错。
- `/爱完美 战绩`：段位与综合分、KD、Rating、ADR、KAST、RWS、爆头率与首杀率、
  常用地图、常用武器与击杀分布、多杀次数、最近十场评分。
- `/爱完美 锐评`：让模型基于数据写锐评，先给称号再分打得好／问题／建议。
- `/爱完美 PK <名字>`：与另一个人比近期战绩，逐项对比由代码算好后交给模型解说。
- `/爱完美 昵称 <名字>`：改 PK 时被叫的名字。
- `/爱完美 解绑`、`/爱完美 状态`、`/爱完美 帮助`。
- 提问「我的 CS2 战绩怎么样」会走同一套数据。

查战绩不需要登录完美平台，没有扫码也没有 token。
