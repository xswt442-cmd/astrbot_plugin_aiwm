# 更新日志

## v0.1.3

- `/爱完美 开一局`（别名 `/爱完美 开局`、`/爱完美 来一局`）：随机生成一局，
  让模型推演过程与结果。数字由代码生成，不让模型自己编；绑定过的话推演会
  贴着玩家的真实水平。输出第一行写明这是推演，不是真实战绩。

## v0.1.2

- 换上新图标。源图在 `icon/aiwm-icon.png`，由 `test/做图标.py` 生成根目录的
  `logo.png`：缩到画布的 92% 让皇冠尖角在圆形裁切下不被切掉，并抠掉源图的
  方形深蓝底，避免裁成圆形后露出一圈方角。

## v0.1.1

- 修 `Main.__init__` 的 `config` 参数：改成可省。AstrBot 在仓库没有配置文件时
  只传 context，声明成必需参数会让插件加载失败。

## v0.1.0

首个版本。

- `/爱完美 绑定 <steamid64>`：绑定 SteamID64。绑定前先探一次接口，打错数字会当场报错。
- `/爱完美 战绩`：段位与综合分、KD、Rating、ADR、KAST、RWS、爆头率与首杀率、
  常用地图、常用武器与击杀分布、多杀次数、最近十场评分。
- `/爱完美 锐评`：让模型基于数据写锐评，先给称号再分打得好／问题／建议。
- `/爱完美 PK <名字>`：与另一个人比近期战绩，逐项对比由代码算好后交给模型解说。
- `/爱完美 昵称 <名字>`：改 PK 时被叫的名字。
- `/爱完美 解绑`、`/爱完美 状态`、`/爱完美 帮助`。
- 提问「我的 CS2 战绩怎么样」会走同一套数据。

查战绩不需要登录完美平台，没有扫码也没有 token。
