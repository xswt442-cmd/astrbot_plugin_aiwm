# 术语

**steamid64** — Steam 用户的 64 位标识，17 位十进制、首位固定为 7，形如
`76561198159976336`。用户可以在 Steam 个人资料页地址末尾看到。前八位
`76561198` 是所有 64 位账号的共同前缀，后面是账号编号。

插件从任意文本里提取这一串数字，所以 Steam 个人资料页网址、启动器参数
`-login 76561198159976336`、提到这个号的聊天记录都能直接粘给绑定指令。

**完美平台** — 完美世界竞技平台，`wmpvp.com`，国服 CS2 的对战平台。另一家
是 5EPlay（`5eplay.com`），本插件不支持。

**注意：本插件读到的不是完美平台的对局数据，是 Valve 官匹的数据。** 接口挂在
`api.wmpvp.com` 下，但返回的是官方匹配的战绩，三条实测证据见 `aiwm/来源.py`。

**PWA ID** — 完美平台给用户分配的内部编号，形如 `21989575`。与 steamid64 是
一对一关系，`appengine.wmpvp.com` 上有接口能互转。插件只在绑定时用 steamid64，
不存 PWA ID。

**综合分** — `rank` 字段，**官匹**的分数形式段位表示。它不是段位名，要折成
名字得按分数段查 `stats.段位名`——那个表是照着这个响应试出来的，不是完美
平台的段位表。

**未定级** — 段位分低于 1000 的状态。接口的历史序列里会出现 0、13、14 这类
小值，都是未定级与定级赛的标记值，不是段位分。照着显示等于告诉模型「这人
段位 14 分」。具体对应哪个定级赛区间没有依据可查，所以一律显示成「未定级」。

**统计场次** — `cnt` 字段，接口统计这些指标所用的对局数量。

**生涯累计胜场** — `historyWinCount` 字段，这个账号累计赢下的对局数。它与
「统计场次」**不是同一个池子**：实测同一个响应里 `cnt` 是 100 而
`historyWinCount` 是 679。所以负场要用 `cnt` 乘胜率反推，拿
`historyWinCount` 去减 `cnt` 会得到负场 0。

**KD** — 击杀数除以死亡数。

**ADR** — Average Damage per Round，每回合平均造成的伤害。衡量一个选手
「每回合能为队伍贡献多少伤害」。

**KAST** — 一局里「拿到过击杀或助攻、或者阵亡但有贡献、或者存活到最后」的
回合数占该局总回合数的比例。衡量稳定性——KAST 低说明经常「什么都没发生」。

**RWS** — Round Win Share，队伍每回合胜率中由该选手贡献的比例。衡量他对
胜负的影响权重，1.0 表示他是队内最关键的那个人。

**爆头率** — 爆头数占总命中数的比例（`headShotRatio`）。

**首杀率** — 拿到第一杀的回合数占该指标统计回合数的比例
（`entryKillRatio`）。反映队伍有没有人开第一枪。

**AWP 击杀占比** — 用 AWP 拿到的击杀数占他全部击杀的比例（`awpKillRatio`）。

**闪光成功率** — 闪光弹生效的次数占投掷次数的比例（`flashSuccessRatio`）。

**PK 名字** — 用户在 `/爱完美 昵称` 里设的名字，PK 时靠它点人。不是 Steam
昵称也不是 QQ 昵称。QQ 官方平台上 @ 别人拿不到对方的用户标识，只能靠名字。

**战绩展示** — 完美平台 App 里的隐私设置。玩家关掉之后，接口对第三方返回
空壳数据（有昵称，统计全空）。插件会照实说明，不会编数字。
